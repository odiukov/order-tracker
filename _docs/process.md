# Development process

Carry forward the workflow used in the first three homework repositories:

1. Define scope and acceptance criteria before implementation.
2. Work through one backlog item at a time with the smallest complete change.
3. Test API behavior and relevant failure paths; use real HTTP checks for deployment.
4. Review the result against the plan and keep observed evidence.
5. Run the complete offline suite before committing code.
6. Write short, human commit messages that describe what changed.
7. Deploy fixes only after tests pass. Never overwrite evidence of the original failure.

Document AI assistance and its verification in `_docs/ai-usage.md`.
